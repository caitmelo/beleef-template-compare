# Beleef template compare

Compares a new design PDF against an approved template PDF and outputs a marked up PDF (red numbered boxes on the design, blue dashed boxes where the template puts each item, numbered notes, summary page).

`original/` holds the exact, unmodified scripts used on 27 Nov 2026 to make the Stone v1, v2 and v3 markups. `SHA256SUMS.txt` lets you check they are untouched. Note: these scripts were written for those Stone files (file paths, trim boxes and element lists are set inside them).
